## ◈ The idea

Ever split a bill with friends, forget who paid last time, or scroll endlessly through WhatsApp to find an old expense?

**Hisaab is built to make that mess disappear.**

Designed for roommates, friends, families, and anyone sharing expenses, Hisaab provides a central place to record spending, understand who owes whom, settle dues, and keep everyone on the same page.

No scattered calculations. No confusing balances. Just a clearer picture of shared money.

## ⚡ What makes Hisaab different?

### 💸 Shared expense tracking
Record shared expenses and maintain a clearer view of contributions, balances, and outstanding dues.

### 📊 A living financial overview
Bring expense information and running balances together instead of maintaining disconnected notes and calculations.

### 🧾 Organized expense history
Review previous transactions with filters for categories, people, and dates.

### 🤝 Friend-wise settlements
Understand who owes whom and make settling shared costs easier to manage.

### 📅 Monthly budgets
Track monthly budgets and carry-over amounts to maintain visibility across spending periods.

### 💬 Conversations in context
Use in-app chat and direct messages to coordinate with the people involved.

### 📋 Smart paste for WhatsApp
Make expense entry more convenient with smart-paste support for WhatsApp content.

### ✨ AI-powered possibilities
Gemini integration brings AI capabilities into the project, creating room for smarter expense workflows.

> **The goal:** less time calculating who owes what, and more time focusing on what actually matters.

## 🎨 Design philosophy

Hisaab isn't designed to feel like another boring spreadsheet.

Its visual direction combines a **maximalist personality** with a **glassmorphism-inspired interface**—aiming for an experience that feels expressive, layered, modern, and easy to explore.

| Design principle | What it brings |
|---|---|
| ◈ Glassmorphism | Translucent surfaces, layered depth, and a modern visual identity |
| ✦ Maximalist styling | Expressive visual details and a distinctive personality |
| ⟡ Visual hierarchy | Important financial information gets clear emphasis |
| ↗ Responsive thinking | A mobile-first approach to everyday use |
| ◎ Functional beauty | Aiming to make the experience attractive without losing its purpose |

The design philosophy is simple: **make managing money feel less like administration and more like using a product people actually enjoy.**

## 🚀 Getting started

Want to explore the project locally? Follow the steps below.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) — use a version compatible with the project's dependencies.
- npm, included with Node.js.
- A Firebase project if you want to configure Firebase-backed features.
- A Gemini API key if you want to run the AI integration.

### 1. Clone the repository

```bash
git clone https://github.com/Malik-Zain-555/Hisaab.git
cd Hisaab
```

### 2. Install dependencies

Inspect the repository to identify the available package files. If it contains a root `package.json`, run:

```bash
npm install
```

If the frontend and backend have separate package files, install dependencies in their respective directories instead.

### 3. Configure environment variables

Check the project's environment example files and configuration to determine the exact variable names required by your version.

Create the appropriate local `.env` file or files and configure the required Firebase and Gemini credentials.

**Important:** Never commit private API keys, service-account credentials, or other secrets to GitHub. Client-side environment variables are not a safe place for server-only secrets.

### 4. Run the application

Check the available scripts in `package.json` before starting the application:

```bash
npm run
```

Then run the appropriate development command defined by the project. For example, a Vite frontend commonly uses:

```bash
npm run dev
```

If the backend is a separate application, start it using its own configured development script.

### 5. Open Hisaab

Open the local URL printed by the development server and explore the application.

> Setup commands may vary depending on the repository's actual folder structure and scripts. Use the project's configuration as the source of truth.

## 🔐 Security matters

Financial information deserves careful handling—even in a personal or experimental project.

- **Authentication:** Verify that protected application functionality requires a valid authenticated session.
- **Database access:** Enforce appropriate Firestore Security Rules for each user's data and shared-group permissions.
- **API secrets:** Keep server-only keys on the server, not in publicly accessible frontend code.
- **Authorization:** Check permissions on the backend rather than relying only on frontend visibility.
- **Validation:** Validate user input before processing or storing it.
- **Testing:** Test access boundaries with multiple accounts and unauthorized requests.

These are important security considerations, not a claim that every item has already been audited or implemented.

**Before using Hisaab for sensitive real-world financial data, review its current security rules, authentication flows, backend authorization, and deployment configuration.**
